# app/corp-app/requirements.txt — app-specific pinned Python extras
#
# PURPOSE
# -------
# This file declares only the Python libraries corp-app needs BEYOND the
# corporate Python standard stack.
#
# WHAT IS NOT LISTED HERE (and must never be added)
# --------------------------------------------------
# The corporate shared Python stack is provided by the corporate Python
# environment:
#
#   - SQLAlchemy      (ORM / DB abstraction layer)
#   - Alembic         (schema migration tool)
#   - Pydantic        (data validation)
#   - python3-PyMySQL (MariaDB/MySQL driver)
#   - python3-psycopg2 (PostgreSQL driver — provided for full corporate DB support)
#
# Adding any of these packages here would shadow the centrally-governed
# versions, violating the single-source-of-truth principle and
# potentially introducing version skew between the migration tool and the
# running service.
#
# ADDING APP-SPECIFIC EXTRAS
# --------------------------
# If corp-app requires a library not in the corporate stack, add it below
# with an exact pinned version (==). Floating ranges (>=, ~=, latest) and
# --upgrade are prohibited. Pinning is the reproducibility guarantee.
#
# Example:
#   requests==2.32.3
#   urllib3==2.2.1
#
# Currently corp-app uses only the corporate stack and the Python standard
# library — no additional dependencies are required.
